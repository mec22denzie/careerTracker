# Career Tracker

## Overview

Career Tracker is a web application designed to help users organize and monitor their job applications and career progress.

## Features

- Track job applications
- Organize application status
- Responsive user interface
- Clean and modern design

## Technologies Used

- React
- JavaScript
- HTML
- CSS

## Key Skills Demonstrated

- React Component Development
- State Management
- Responsive Web Design
- Modern JavaScript (ES6+)
- UI/UX Design
